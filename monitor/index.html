指标口径

本机采集
  • 成功率 = RPC 成功数 / 已提交数，超时和不可用都计入分母。
  • 丢序 / 缺失来自 Event 序号跳变；续收回放是断连后服务端按缓存补发的条数。
  • 平均延迟统计已完成调用，包含超时和失败；在途数不参与延迟。
  • 同一角色只保留最新一份快照，避免重复启动导致累计翻倍。
  • 顶部的 DDS / SOME/IP 切换只过滤当前视图，不会停止另一侧的演示。
数据来源：每个演示进程周期写出 metrics-<role>-<pid>.json，日志按行写成 JSONL。 面板默认只读取运行数据；控制按钮只会调用项目内置脚本启动演示或测试，不执行任意命令。 同一角色只展示最新一份快照，避免重复启动导致累计翻倍。
